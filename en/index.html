02

Current research

My current research focuses on problems at the intersection of symbolic computation, network coding, and information theory. In particular, I study information-theoretic secure coding for 6G integrated space–air–ground–sea networks, lightweight pollution defense for resource-constrained nodes, and the joint design of confidentiality and integrity using symbolic computation. This work translates recoverability, secrecy, integrity, and coding feasibility into finite-field rank conditions and polynomial constraints, and uses characteristic-set and symbolic elimination methods for analysis and code construction.

01

Multipath Information-Theoretic Secure Coding for 6G Integrated Space–Air–Ground–Sea Networks

For heterogeneous links and dynamic topologies in 6G integrated space–air–ground–sea networks, this topic develops nonuniform, probabilistic eavesdropping models, studies multipath random linear network coding, and translates recoverability, secrecy, and coding feasibility into finite-field rank conditions and algebraic constraints.

02

Lightweight Pollution Defense for Resource-Constrained Nodes

This topic studies lightweight homomorphic authentication and hop-by-hop pollution detection so that intermediate nodes can validate coded packets without decoding. Symmetric cryptographic primitives, probabilistic sampling, and load allocation are used to reduce computation, communication, and latency overhead.

03

Joint Confidentiality and Integrity Design and Performance Trade-offs via Symbolic Computation

This topic expresses confidentiality, integrity, and coding feasibility as finite-field rank conditions and polynomial systems. Characteristic-set and symbolic-elimination methods are used to analyze compatibility, construct coding schemes, and study trade-offs among secure rate, detection rate, computational cost, and latency.

Latest news

2026.09

New manuscript completed. We recently completed a new manuscript on binary linear network coding under prescribed adversarial erasures and bit flips, with Xingbing Chen as the first author. Extending our previous work on erasures, this paper develops a pattern-testing decoder, establishes algebraic necessary and sufficient conditions for unique decodability, uses the binary characteristic-set method to construct all uniquely-decodable linear network codes, and derives an upper bound on the number of distinguishable bit-flip patterns. The manuscript is intended for submission to IEEE Transactions on Information Theory (IEEE TIT).
